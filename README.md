# kintone-ai-automation

Automating order and quote-request workflows with kintone, TypeScript, and AI.

## Background

At a previous job (an e-commerce company with about 30 employees), I built:

- **kintone apps** for orders and quote requests, linking one order to many quote requests
- **A Python app** that read kintone data, looked up suppliers, and sent quote requests and purchase orders by email and fax (eFax)

Results: zero missed orders (previously about one per month) and about 2 hours saved per day.

This repository rebuilds that system with modern tools and extends it with AI.
